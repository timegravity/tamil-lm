# Dictionary pack: license register (verified by fetch, 2026-09-10)

Same method as data/packs/cooking/LICENSES.md: each license was read from the source itself on 2026-09-10,
through the MediaWiki `siteinfo` rightsinfo API for the wikis and from the page HTML for the other sites,
and is quoted here as found. The fetched pages are cached verbatim under `data/raw/packs/dictionary/`
(`rightsinfo.json`, `dsal_pages.json`, `archive_org_items.json`) so every quote below can be re-read.
Decision key: include = used in the pack; exclude = not used, with the reason. Nothing NC-licensed, nothing
whose license could not be read from the source itself, and no derivative of an ND-licensed database is in
the pack.

Attribution requirement: every entry and every chunk carries its own `word`, `url` and `license`, so the
CC BY-SA 4.0 attribution and share-alike terms can be honoured per answer at serving time, the same rule as
the Wikipedia-derived rows in data/round3/LICENSES.md (decision 2026-09-08).

## Notes

- The three named historical dictionaries are the reason this pack exists, and none of them is in it. That is
  a fact about the copies available in 2026, not about the works: the printed books are public domain, but the
  only machine-readable texts are DSAL's keyed databases (NC-ND, or unlicensed) and archive.org OCR that does
  not read either script. A future version can add them by re-OCRing the Commons or archive.org page images
  with a Tamil-capable engine and proofreading; the Wikisource route would give the result a verified license
  automatically.
- Share-alike: any redistribution of entries_unscanned.jsonl, chunks_unscanned.jsonl or of text derived from
  them stays under CC BY-SA 4.0, with attribution to the Wiktionary page each row carries in `url`.
- Family-safe: entries the source itself marks as slurs or sexual terms were skipped at build time (Tamil
  Wiktionary category வசைச்சொற்கள்; English Wiktionary vulgar, offensive, slur and profanity labels and the
  Genitalia, Prostitution and Pornography topics). The lexicon scan over every chunk is run separately by the
  coordinator; `scan` is `pending` in manifest.json until then.
